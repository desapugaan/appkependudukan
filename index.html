Masuk terlebih dahulu untuk memulai pendataan. Data diproses oleh Google Apps Script dan Gemini, bukan disimpan di GitHub Pages.

🔒 Akses khusus petugas terotorisasi. Jangan gunakan dokumen KK asli sebelum keamanan dan kebijakan pemrosesan data disetujui.

1. Pilih cara memasukkan dokumen

Gunakan kamera HP, file dokumen, atau isi langsung tanpa AI.

LANGKAH 1

Ambil foto seluruh lembar Kartu Keluarga

Pastikan tulisan terbaca, pencahayaan cukup, dan semua anggota keluarga terlihat.

Memilih foto akan langsung menjalankan analisis Gemini.

Unggah foto atau dokumen KK

Mendukung JPG, PNG, WEBP, PDF, dan DOCX (Word baru). PDF hasil scan dibaca secara visual; teks dan gambar di dalam DOCX juga dapat dianalisis.

Batas pemrosesan 4 MB per file. Format .doc lama perlu disimpan sebagai .docx atau PDF.

Entri tanpa scan

Isi nomor KK, RT, dan data anggota pada formulir di bawah. Gunakan tombol “Tambah anggota” untuk setiap anggota keluarga.
